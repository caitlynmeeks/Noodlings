# File Formats

Reference for all Noodlings file formats.

---

| Format | Extension | Purpose |
|--------|-----------|---------|
| [Radiance](radiance.md) | `.radiance` | Gaussian splat models |
| [Neural Canvas](nncanvas.md) | `.nncanvas` | Neural network graphs |
| [Recipe](recipe.md) | `recipe.yaml` | Noodling definitions |
| [Stage](stage.md) | `stage.yaml` | World scenes |
| [Assembly](assembly.md) | `assembly.yaml` | Cognitive architectures |
| [Project](project.md) | `project.yaml` | Project metadata |
