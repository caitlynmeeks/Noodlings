# NoodleMUSH Commands

Complete command reference.

---

## Communication

| Command | Description |
|---------|-------------|
| `say <message>` | Speak to everyone in the room |
| `whisper <target> <message>` | Private message to one entity |
| `emote <action>` | Perform an action (*You wave*) |

## Navigation

| Command | Description |
|---------|-------------|
| `look` | Describe current room |
| `look <target>` | Examine something specific |
| `go <direction>` | Move to adjacent room |
| `@teleport <room>` | Jump to any room (admin) |

## Noodling Management

| Command | Description |
|---------|-------------|
| `@rez <name>` | Spawn a Noodling |
| `@derez <name>` | Remove a Noodling |
| `@observe <name>` | View phenomenal state |
| `@relationship <name>` | See how they perceive you |

## World Building

| Command | Description |
|---------|-------------|
| `@dig <room_name>` | Create a new room |
| `@link <direction> <room>` | Connect rooms |
| `@describe <target> <text>` | Set description |
| `@spawn <prim>` | Place a prop |

## Diagnostics

| Command | Description |
|---------|-------------|
| `@status` | Server status |
| `@agents` | List active Noodlings |
| `@step <name>` | Single-step cognition |

---

## Command Syntax

- `<required>` - Must provide
- `[optional]` - Can omit
- `target` - Noodling name, prop name, or "here"
