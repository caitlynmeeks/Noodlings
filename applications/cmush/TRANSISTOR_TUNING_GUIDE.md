# Transistor Tuning Guide

**Created**: November 26, 2025
**Exemplar**: Red Fire Anklebiter v2.0

---

## Core Principle

**Each transistor has ONE focused job. Zero overlap. Maximum signal.**

If two transistors say the same thing in different words, ONE needs to change or die.

---

## The Six Transistor Jobs (Standard Configuration)

### 1. IntuitionTransistor - CONTEXTUAL FACTS
**Job**: WHO, WHERE, WHAT - Spatial and social awareness
**NOT**: Emotion, personality, interpretation
**Output**: "Caity is talking TO ME. She's 5 feet away holding candy."

### 2. AffectTransistor - VISCERAL EMOTION
**Job**: Raw emotional sensations in the body
**NOT**: Wit, sarcasm, clever remarks
**Output**: "Flames SURGING - wanna JUMP!" (fire imp) or "Butterflies in stomach" (human)

### 3. PersonalityTransistor - CHARACTER VOICE
**Job**: How THIS specific character expresses themselves
**NOT**: Generic emotion, physical sensations
**Output**: "Oh PLEASE." (Red's sarcasm) or "Fascinating." (Spock's logic)

### 4. CulturalTransistor - TRIBAL BELIEFS
**Job**: Cultural/tribal perspective distinct from personality
**NOT**: Personality overlap
**Output**: "Ankle biting is how gremlins GREET" or "In my culture, we bow first"

### 5. MemoryTransistor - PAST CONNECTIONS
**Job**: Relevant memories that color current perception
**NOT**: Echoing input
**Output**: "Last time Caity shared candy, got HYPER for hours" or EMPTY

### 6. EmbodyComponent - PHYSICAL IMPULSES
**Job**: What the body WANTS TO DO physically
**NOT**: Emotional reactions
**Output**: "*claws tapping* *tail snapping*" or "*fidgets with hands*"

---

## How to Spot Redundancy

**Bad**: All transistors saying variations of "I'm angry and sarcastic"

**Good**: Each transistor contributes DISTINCT perspective:
- Intuition: "They're talking to Toad, not me"
- Affect: "Flames burning BRIGHT with excitement"
- Personality: "Oh PLEASE, another speech?"
- Cultural: "Gremlin code says bite first, questions never"
- Memory: "Last time this happened, I got in trouble"
- Embody: "*bounces impatiently* *claws tapping*"

Read them separately - can you TELL which transistor each line came from? If not, they're too similar.

---

## Tuning Process

### Step 1: Test with Real Input

Send perception, check manifold output.

### Step 2: Identify Overlap

Which transistors said basically the same thing?

Example from Red's output:
- PersonalityTransistor: "You think you're so smart..."
- CulturalTransistor: "I see through BS..."

SAME MESSAGE. Redundant!

### Step 3: Sharpen Focus

**PersonalityTransistor**: Keep the WIT and VOICE
- "Oh PLEASE." (short, sharp, Red's style)

**CulturalTransistor**: Focus on GREMLIN tribal beliefs
- "Ankle biting is how we SAY HELLO" (cultural rule, not personality)

### Step 4: Reduce Salience of Redundant Ones

If Cultural keeps overlapping Personality, reduce salience: 0.75 -> 0.60

### Step 5: Test Again

Iterate until each transistor's contribution is OBVIOUS and UNIQUE.

## Red Fire Anklebiter - Exemplary Configuration

### Design Choices

1. **Intuition (0.90)**: HIGH - Spatial context is critical
2. **Affect (0.85)**: HIGH - Fire-body emotions are central to Red
3. **Personality (0.80)**: HIGH - Red's wit defines him
4. **Cultural (0.60)**: REDUCED - Gremlin culture is secondary
5. **Memory (0.70)**: MEDIUM - Relevant when triggered
6. **Embody (0.95)**: HIGH - Physical fidgeting is constant

### Prompt Principles

**All prompts follow**:
- "YOUR JOB:" - Clear single purpose
- "NO X, NO Y" - Explicit boundaries
- "JUST Z" - Focus directive
- "1 sentence" - Length limit
- "Example:" - Concrete sample

### Expected Manifold Output

Input: "hi red"

Transistor outputs:
- Intuition: "Caity is talking TO ME directly."
- Affect: "Flames CRACKLING with excitement - wanna RESPOND!"
- Personality: "Oh HEY there!"
- Cultural: "Greeting detected - time to bite ankles!" (or EMPTY)
- Memory: "Caity always brings CHAOS" (or EMPTY)
- Embody: "*bounces on toes* *tail snapping*"

Manifold blend:
"Oh HEY there! *flames crackling excitedly* *bounces on toes* Ready for some CHAOS?!"

**Each line traceable to specific transistor. No redundancy. Tight and focused.**

## Success Criteria

Tuning is complete when:

1. ✅ Each transistor output is IMMEDIATELY distinguishable
2. ✅ No two transistors saying the same thing
3. ✅ Manifold blend feels like FUSION, not REPETITION
4. ✅ Removing any transistor would LOSE something irreplaceable
5. ✅ Prompt length < 200 words (tight!)
6. ✅ Output length 1-2 sentences max (no essays!)

---

## Anti-Patterns to Avoid

**DON'T**:
- Long-winded philosophical explanations
- Poetic descriptions that all sound the same
- Transistors echoing each other
- Generic advice ("just be yourself!")
- Flowery language that adds no information

**DO**:
- Concrete, specific outputs
- Tight length constraints (1 sentence!)
- Clear job boundaries
- Character-specific voice
- Actionable content
